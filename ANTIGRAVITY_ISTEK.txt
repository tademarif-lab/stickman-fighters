YAPILACAKLAR (sırayla):

1) Bu bilgisayardaki "GITHUB_YUKLE" klasörünü GitHub'a yükle.
   Yüklenecek dosyalar:
   - SITE/            (klasör, içinde index.html, favicon.png,
                       APK_YAPIMI.md, MOBIL_REHBERI.md, ONLINE_REHBERI.md,
                       README.md, ve indir/ klasörü)
   - .github/workflows/site.yml
   - .github/workflows/android-apk.yml
   - APK_YAPIMI.md

   GitHub API ile yüklemek en kolay. Bunu kullan:

   ```python
   import base64, json, urllib.request

   OWNER = "tademarif-lab"
   REPO  = "stickman-fighters"
   BRANCH = "master"
   TOKEN = "..."      # ben vereceğim ya da ortam değişkeninden oku

   def yukle(yol, dosya):
       url = "https://api.github.com/repos/%s/%s/contents/%s" % (OWNER, REPO, yol)
       h = {"Authorization": "Bearer " + TOKEN,
            "Accept": "application/vnd.github+json",
            "X-GitHub-Api-Version": "2022-11-28"}
       # var mı kontrol et (sha almak için)
       sha = None
       try:
           r = urllib.request.Request(url, headers=h)
           with urllib.request.urlopen(r) as resp:
               sha = json.loads(resp.read())["sha"]
       except Exception:
           pass
       icerik = base64.b64encode(open(dosya, "rb").read()).decode()
       govde = {"message": "site: " + yol,
                "content": icerik,
                "branch": BRANCH}
       if sha:
           govde["sha"] = sha
         # yoksa yeni olustur
       r = urllib.request.Request(
           url, data=json.dumps(govde).encode(),
           headers=dict(h, **{"Content-Type": "application/json"}),
           method="PUT")
       with urllib.request.urlopen(r) as resp:
           print(resp.status, yol)
   ```

   `SITE` klasöründeki HER dosya için `yukle()` çağır
   (klasör yapısını koruyarak, örn. "SITE/index.html").

   GitHub'da "Upload files" ile de yapabilirsin ama `.github` klasörü
   gizli dosya olduğu için tarayıcı onu atabilir. API daha güvenli.
